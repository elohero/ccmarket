# Общая база сделок — установка

## 1. Проект на Vercel

Создай новый проект (или используй существующий) со структурой:

```
/api/sync.js      <- файл sync.js из этой папки
/package.json
```

`package.json`:

```json
{
  "name": "cc-market-sync",
  "version": "1.0.0",
  "type": "module",
  "dependencies": {
    "@upstash/redis": "^1.34.0"
  }
}
```

## 2. Upstash Redis

В дашборде проекта: **Storage → Create Database → Upstash for Redis**, подключить к проекту.

Vercel сам добавит переменные окружения `UPSTASH_REDIS_REST_URL` и
`UPSTASH_REDIS_REST_TOKEN` — `Redis.fromEnv()` читает именно их, руками
ничего прописывать не нужно.

Задеплоить. Проверка: открой `https://ТВОЙ-ПРОЕКТ.vercel.app/api/sync`
в браузере — должно вернуться `{"ok":true,"service":"cc-market-sync"}`.

## 3. Настройка скрипта

`cc_market_history.lua` кинуть в `moonloader/`, запустить игру, зайти на
сервер, ввести `/cc` один раз — создастся `moonloader/config/cc_market.ini`.

Выйти из игры и дописать в ini:

```ini
[sync]
enabled=true
url=https://ТВОЙ-ПРОЕКТ.vercel.app/api/sync
key=
client=
lastIds=
```

`client` не трогать — заполнится сам уникальным id при первом запуске.
У второго человека он будет свой, это и различает клиентов.

То же самое сделать у друга: тот же `url`, свой пустой `client`.

## 4. Несколько серверов

Сервер, на котором ты играешь, добавляется сам. Остальные — командой
в игре или руками в ini:

```
/ccadd 201        <- добавить Vice City
/cclist           <- показать, что отслеживается
```

```ini
[main]
servers=32,201
```

Vice City числится под номером 201, но в запросе к API уходит как 0 —
скрипт делает эту подмену сам.

Аренда сборщика на сервере **отдельная**. То есть вы можете разделиться:
один собирает основной сервер, другой Vice City, — это происходит
автоматически, кто первый занял. Или один человек тянет оба, если
второй оффлайн.

Серверы опрашиваются по очереди, а не разом. Если API откажет по
какому-то серверу, интервал для него растёт (до 8x), чтобы не долбить
чужое API впустую; остальные продолжают работать нормально.

## 5. Валюты

На Vice City ходит VC$, на остальных серверах SA$. Статистика по каждому
серверу считается отдельно, так что внутри сервера всё корректно —
проблема только при сравнении серверов между собой.

Скрипт подписывает валюту в карточке предмета и предупреждает, если
в режиме «Все серверы» включена сортировка по цене.

Настройка в ini (значения по умолчанию):

```ini
[currency]
default=SA$
map=201:VC$
rates=
```

Если знаешь примерный курс — впиши его в `rates` в формате
`номер:множитель`, где множитель это сколько SA$ дают за 1 VC$.
Например при курсе 1 VC$ = 0.5 SA$:

```ini
rates=201:0.5
```

Тогда в карточке предмета с Vice City появится строка с пересчётом
в SA$. Пока `rates` пустая, ничего не пересчитывается — я курс
не выдумываю, впиши сам.

## 6. Пароль (опционально)

Если решишь закрыть эндпоинт: в Vercel добавь переменную окружения
`SYNC_KEY` с любой строкой, передеплой, и пропиши то же значение
в `key=` у обоих в ini. Пока `SYNC_KEY` не задана — проверки нет.

## Как это работает

- Все клиенты раз в N секунд шлют **один** запрос на все серверы сразу:
  продление аренды, отправка накопленного, получение нового.
- Аренду на каждый игровой сервер держит один человек — он и опрашивает
  рынок. Остальные рынок не трогают, только читают ленту.
- Аренда живёт 5 минут. Вышел сборщик — другой подхватит за это время.

Частота запроса к базе зависит от роли:

| Роль | Интервал |
|---|---|
| Сборщик | 180 сек (отправка + продление аренды) |
| Читатель, окно открыто | 120 сек |
| Читатель, окно закрыто | 300 сек (только проверка аренды) |

Рынок сборщик опрашивает раз в 60 сек — это настраивается отдельно,
в `[main] refreshSec`, и на расход базы не влияет.

Читателю фоновый обмен нужен только чтобы перехватить роль, если
сборщик выпал. Данные он подтягивает в момент открытия окна.

## Лимиты

Бесплатный тариф Upstash — 500 000 команд в месяц (256 МБ данных).

Расчёт на троих и два игровых сервера, при условии что один человек
онлайн круглосуточно:

| | команд/сутки |
|---|---|
| Сборщик | ~4 800 |
| Два читателя | ~2 700 |
| **Итого** | **~7 500** |

Около 230 000 команд в месяц — влезает с двукратным запасом.
Четвёртый человек или третий сервер этот запас не съедят.

Если всё же выйдете за лимит, дальше идёт $0.20 за 100 000 команд.

В базе хранится последние 200 000 сделок на сервер, лента живёт 60 дней.
Меняется константами `MAX_TRADES` и `FEED_TTL` в `sync.js`.
Интервалы обмена — константами `PUSH_EVERY`, `OPEN_EVERY`, `IDLE_EVERY`
в начале lua-скрипта.
